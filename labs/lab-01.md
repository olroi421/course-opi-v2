- вивести результати обчислень у консоль у вигляді читабельного звіту;

### Рівень 2

- реалізувати базову валідацію вхідних даних (обробка відсутніх/некоректних значень без падіння програми);
- реалізувати одну додаткову функцію аналізу на вибір (медіана, стандартне відхилення, пошук записів за критерієм користувача, інтерактивний режим введення тощо).

## 📚 Теоретичні відомості

### Python: базовий синтаксис

**Python** — інтерпретована мова програмування високого рівня з чітким та лаконічним синтаксисом, що робить її зручною для початку вивчення програмування. Основні елементи, необхідні для виконання роботи:

- **змінні та типи даних** — числа (`int`, `float`), рядки (`str`), логічний тип (`bool`);
- **структури даних** — список (`list`), словник (`dict`) — список словників зручний для представлення набору однотипних записів (наприклад, рядків таблиці);
- **умовні конструкції** — `if` / `elif` / `else`;
- **цикли** — `for`, `while`, зокрема ітерація по списку записів;
- **функції** — `def`, параметри, значення що повертаються, docstring для опису призначення функції;
- **модулі** — виділення функцій в окремий `.py`-файл та імпорт через `import`.

### Робота з файлами CSV та JSON

Для читання й запису CSV зручно використовувати стандартний модуль `csv`:

```python
import csv

with open("data.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    records = [row for row in reader]
```

Запис результату у JSON — стандартний модуль `json`:

```python
import json

with open("result.json", "w", encoding="utf-8") as f:
    json.dump(records, f, ensure_ascii=False, indent=2)
```

### Модульність

Функції обробки даних доцільно виносити в окремий файл-модуль, наприклад `data_analyzer.py`, а в головному файлі `main.py` — імпортувати й викликати:

```python
# data_analyzer.py
def average(values: list[float]) -> float:
    """Обчислює середнє арифметичне списку значень."""
    return sum(values) / len(values) if values else 0.0
```

```python
# main.py
from data_analyzer import average

print(average([4, 5, 6]))
```

### Markdown: мова розмітки для документації

Звіт до цієї та наступних лабораторних робіт оформлюється у форматі **Markdown** (`.md`) — надалі вся технічна документація в курсі (звіти, README проєктів тощо) також писатиметься саме в цьому форматі, тож варто опанувати його вже зараз.

**Markdown** — це легка мова розмітки тексту: замість візуального редактора (як у Word) форматування задається простими текстовими символами, а сам файл при цьому лишається читабельним навіть без "рендерингу". Найуживаніші елементи:

- заголовки — `#`, `##`, `###` (кількість `#` відповідає рівню заголовка);
- виділення тексту — `**жирний**`, `*курсив*`;
- списки — маркований (`-` або `*`) та нумерований (`1.`, `2.`, ...);
- посилання — `[текст посилання](URL)`;
- зображення — `![опис](шлях_або_URL)`;
- код — рядковий `` `код` `` та блоки коду, обгорнуті потрійними зворотними лапками (за потреби з позначенням мови, наприклад ```` ```python ````);
- таблиці та цитати (`>`) — для більш структурованого викладу.

> [!TIP]
> **Де подивитись і потренуватись:**
> - [Markdown Guide — Basic Syntax](https://www.markdownguide.org/basic-syntax/) — стислий довідник з усім основним синтаксисом з прикладами;
> - [CommonMark: інтерактивний тренажер](https://commonmark.org/help/tutorial/) — покроковий тренажер, де можна одразу спробувати кожен елемент розмітки;
> - [GitHub Docs: Basic writing and formatting syntax](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) — той самий синтаксис у контексті GitHub (знадобиться і для README проєктів у наступних лабах).
>
> Писати та перевіряти Markdown-файли зручно прямо в VS Code — він показує попередній перегляд файлу (`Ctrl+Shift+V`) поруч із текстом розмітки.

## 📋 Варіанти завдань

Кожен варіант передбачає обробку CSV-файлу з відповідними даними. Конкретні показники для обчислення (рівень 1), спосіб категоризації (рівень 2) та ідею додаткової функції (рівень 3) студент узгоджує з викладачем або обирає самостійно в межах теми варіанта.

1. **Успішність студентів групи** — ПІБ, оцінки з 3-4 дисциплін. Приклад показників: середній бал студента/групи, найкращий/найгірший результат, розподіл за категоріями "відмінно"/"добре"/"задовільно"/"незадовільно".
2. **Облік товарів на складі** — назва товару, категорія, кількість, ціна за одиницю. Приклад показників: загальна вартість запасів, товари з кількістю нижче порогу, розподіл за категоріями.
3. **Погодні спостереження** — дата, місто, температура, опади. Приклад показників: середня температура за період/містом, дні з опадами, найспекотніший/найхолодніший день.
4. **Особисті фінанси** — дата, категорія витрат, сума, опис. Приклад показників: сума витрат за категорією, місяць з найбільшими витратами, розподіл витрат за категоріями.
5. **Бібліотечний каталог** — назва книги, автор, рік видання, жанр, наявність. Приклад показників: кількість книг за жанром, найстаріша/найновіша книга, відсоток книг у наявності.
6. **Результати спортивних змагань** — учасник, дисципліна, результат (час/очки), місце. Приклад показників: середній результат за дисципліною, призери, розподіл учасників за дисциплінами.
7. **Облік співробітників** — ПІБ, відділ, посада, зарплата, стаж роботи. Приклад показників: середня зарплата за відділом, співробітники зі стажем понад N років, розподіл за посадами.
8. **Продажі інтернет-магазину** — назва товару, категорія, кількість продано, дата продажу, ціна. Приклад показників: загальна виручка, найпопулярніший товар/категорія, продажі за період.
9. **Тренувальний щоденник** — дата, тип вправи, кількість повторень/підходів, вага/тривалість. Приклад показників: загальний обсяг навантаження за тип вправи, прогрес за період, найінтенсивніший день.
10. **Пасажирські перевезення** — номер рейсу, дата, напрямок, кількість пасажирів, ціна квитка. Приклад показників: загальна виручка за рейсом/напрямком, середня заповненість, найпопулярніший напрямок.
